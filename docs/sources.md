# MOSFET 데이터 출처와 모델 기준

## 1. 사용 소자
- 제조사: Infineon
- 부품명: IAUTN12S5N018T
- 소자: 자동차용 OptiMOS 5 N채널 Power MOSFET
- 데이터시트: Rev. 1.10, 2024-11-14
- 원문 파일: [데이터시트](datasheets/IAUTN12S5N018T_datasheet.pdf)

## 2. 온도별 저항 데이터
- 출처: 데이터시트 7쪽, Fig. 8
- 사용 곡선: VGS = 10 V, ID = 100 A 조건의 아래쪽 곡선
- 데이터 범위: Tj = 25~175°C, 총 7개 점
- 저항 단위: mΩ
- 해당 값은 전형 특성 그래프에서 추출한 근삿값이며 실측값이 아니다.
- 원본 엑셀: data/raw/RDSon_vs_Tj.xlsx
- CSV: data/raw/rds_vs_temperature.csv

## 3. 저항 기준
- 데이터시트 4쪽 표: 25°C에서 Typ 1.5 mΩ, Max 1.8 mΩ
- 표의 조건: VGS = 10 V, ID = 100 A
- 본 온도 모델은 추출 데이터의 25°C 값인 1.49 mΩ를 기준으로 사용한다.
- 고정 저항 비교에도 동일한 1.49 mΩ를 사용한다.
- 계산에서 Ω가 필요하면 mΩ 값에 0.001을 곱한다.

## 4. 열 모델 기준
- 출처: 데이터시트 4쪽
- RthJC = 0.42 K/W: Top 방향 접합부–케이스 열저항의 최댓값
- 이 값을 사용하는 모델에서 Tc는 상부 케이스 온도를 의미한다.
- Tc를 주변 공기 온도와 동일한 값으로 취급하지 않는다.

## 5. 적용 범위와 가정
- 온도 곡선은 ID = 100 A에서 제공된 자료이다.
- 다른 전류에 같은 저항 곡선을 적용할 경우 전류 의존성을
  무시한 근사 모델임을 명시한다.
- 추출 범위 밖으로 온도 모델을 외삽하지 않는다.
- 정상상태 열 계산 결과도 접합온도 허용 범위 내인지 확인한다.
