# MOSFET 시험 데이터 사용 안내

## 1. 목적
온도와 자기발열을 반영한 MOSFET 모델에서 VDS를 계산하고,
고정 저항으로 전류를 추정했을 때의 오차를 평가한 데이터이다.
실제 측정값이 아닌 Python 모델 계산값이다.

## 2. 파일 위치
- 시험 데이터: data/processed/mosfet_test_cases.csv
- 비교 그래프: results/figures/current_estimation_error_vs_tc.png
- 생성 코드: notebooks/02_steady_state_electro_thermal.ipynb
- 소자 및 데이터 출처: docs/sources.md

## 3. 시험 조건
- MOSFET: Infineon IAUTN12S5N018T
- 기준 전류: 25, 50, 75, 100 A
- 케이스 온도: 25, 50, 75, 100, 125, 150°C
- 총 조건 수: 24개
- 고정 저항 추정 기준: 1.49 mΩ
- 접합부–케이스 열저항: 0.42 K/W, Top 방향 최댓값

## 4. 열별 의미

| 열 | 의미 |
|---|---|
| I_true (A) | 모델에 입력한 기준 전류 |
| Tc (°C) | 입력한 상부 케이스 온도 |
| Tj (°C) | 자기발열을 반영해 계산한 정상상태 접합온도 |
| Rds (mΩ) | 계산된 접합온도에서의 도통저항 |
| Ploss (W) | 전도손실 |
| VDS (V) | MOSFET 도통 상태의 양단 전압 |
| I_fixed (A) | VDS를 고정 저항으로 나눈 추정 전류 |
| Error (A) | 추정 전류 - 기준 전류 |
| Error (%) | 전류 오차 / 기준 전류 × 100 |

## 5. 팀원별 사용 방법
- 2번: 각 조건의 VDS를 측정·증폭 회로의 입력으로 사용한다.
- 3번: data/raw/rds_vs_temperature.csv의 온도별 저항을
  보상 회로 설계에 사용한다.
- 4번: 회로 출력과 이 CSV를 기준 전류·케이스 온도 조합으로 연결하고,
  I_true와 추정 전류를 비교한다.
- 현재 24개 조건에서 VDS 범위는 약 0.037328~0.290599 V이다.
- VDS는 드레인과 소스 사이의 차동 전압이다.
  회로의 공통모드 전압과 전원 조건은 별도로 정해야 한다.

## 6. 모델 가정과 한계
- VGS = 10 V, ID = 100 A 조건의 전형 저항–온도 곡선을 사용했다.
- 그래프에서 추출한 점 사이의 저항은 선형 보간했다.
- 다른 전류에서도 같은 저항–온도 곡선을 사용하는 근사 모델이다.
- 정상상태 전도손실과 자기발열을 고려했으며,
  스위칭 손실과 시간에 따른 열 응답은 포함하지 않았다.
- Tc는 주변 공기 온도가 아니다.
- NTC 센서온도 Ts는 현재 CSV에 포함하지 않았다.
  통합 시험 전에 Ts의 설정 방법을 정해야 한다.
- Tj는 모델 내부의 기준값이다. 실제 센서가 측정한 값으로 취급하지 않는다.
- 현재 결과에는 초기 소자 편차, 증폭기 오차,
  NTC 보상 및 Calibration이 포함되지 않았다.
