| 항목          | 오늘 사용할 기준                              |
| ----------- | -------------------------------------- |
| 공통 입력 데이터   | `data/processed/mosfet_test_cases.csv` |
| 시험 조건       | 25·50·75·100 A × 케이스 온도 6개 = 24개       |
| U1 입력       | 각 행의 `VDS (V)`                         |
| U1 목표 이득    | 현재처럼 **2배**                            |
| U1 전원·측정 조건 | 현재처럼 5 V 전원, 소스 측 입력은 GND              |
| U1 출력 이름    | 회로에 이미 있는 `V_pre`                      |
| 조건 연결 방법    | `I_true (A)`와 `Tc (°C)` 조합으로 연결        |
| 첫 보정 기준점    | **50 A, Tc=25°C를 제안**. 합의해서 하나로 고정     |
| 첫 온도보상 시험   | `Ts=Tj`인 이상적인 온도 일치 조건부터 시작            |
| 다음 온도보상 시험  | `Ts=Tc`로 바꿔 접합온도와 센서온도가 다른 경우 확인       |
